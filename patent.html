테마 기반 AI 이미지 자동 생성 시스템

System and Method for Theme-Based Automatic Image Generation Using AI

요약:

본 발명은 미리 정의된 이미지 테마의 구조를 유지하면서 사용자 입력 프롬프트를 기반으로 AI 이미지 생성 엔진을 활용하여 고품질의 마케팅 이미지를 자동으로 생성하는 시스템 및 방법에 관한 것이다. 특히, 사용자의 브랜드 로고를 생성된 이미지에 자동으로 삽입하고, 동적으로 새로운 테마를 확장할 수 있는 기술이 포함된다.

2. 기술분야

2.1 기술 분류

국제분류: G06F 17/28, G06T 1/00

기술분야: 인공지능 기반 이미지 생성 기술

적용분야: 마케팅 콘텐츠 자동 생성, 광고 소재 제작, 브랜딩

2.2 기술의 배경

전통적으로 고품질의 마케팅 이미지 제작은 전문 디자인 팀이 수작업으로 진행되어 시간과 비용이 많이 소요되었다.

최근 GPT Image2(DALL-E 3) 등의 생성형 AI 기술의 발전으로 프롬프트 기반의 이미지 자동 생성이 가능해졌으나, 브랜드 아이덴티티를 일관성 있게 유지하기 어려운 문제가 있었다.

본 발명은 이러한 문제를 해결하기 위해 테마 기반의 구조화된 이미지 생성 방식을 제안한다.

2.3 선행기술의 한계

선행기술 한계점 본 발명의 개선
텍스트 기반 이미지 생성 일관성 없는 스타일 테마 기반 구조 유지
수작업 디자인 시간과 비용 소요 자동화된 대량 생성
로고 수작업 삽입 품질 편차 발생 자동 Canvas API 처리

3. 해결과제

3.1 발명이 해결하려는 문제점

문제점 1: 일관성 있는 브랜드 이미지 생성의 어려움

기존의 텍스트 기반 이미지 생성 AI는 매번 다른 스타일의 이미지를 생성하여 브랜드 아이덴티티를 일관성 있게 유지하기 어렵다.

문제점 2: 로고 삽입의 비효율성

생성된 이미지에 브랜드 로고를 추가하는 과정이 수작업이거나 복잡하여 대량의 이미지 생성 시 비용이 증가한다.

문제점 3: 마케팅 콘텐츠 제작 시간 증가

디자이너의 개입이 많아서 이미지 제작에 상당한 시간이 소요되고, 변경 요청에 대한 반영이 지연된다.

문제점 4: 테마 확장의 제한성

새로운 이미지 스타일을 추가하려면 복잡한 개발 과정을 거쳐야 하고, 최종 사용자가 쉽게 테마를 추가할 수 없다.

3.2 해결과제 정리

  • ✅ 일관성 있는 테마 기반 이미지 생성
  • ✅ 로고 자동 삽입 시스템 개발
  • ✅ 대량의 고품질 콘텐츠 신속 생성
  • ✅ 사용자 친화적 테마 확장 기능

4. 발명의 해결수단

4.1 기술적 해결수단

1️⃣ 테마 메타데이터 시스템

각 이미지 테마에 대해 다음의 메타데이터를 정의합니다:

  • 테마 ID 및 명칭
  • 이미지 구조 정보 (레이아웃, 영역 배치)
  • 색상 팔레트
  • 생성 가이드라인

2️⃣ Canvas 기반 로고 오버레이

HTML5 Canvas API를 이용하여 생성된 이미지에 로고를 자동으로 합성합니다:

  • 이미지 좌표 자동 계산
  • 로고 크기 동적 조절
  • 배치 위치 최적화

3️⃣ 프롬프트 동적 구성

선택된 테마의 메타데이터를 이용하여 다음과 같이 프롬프트를 동적으로 구성합니다:

final_prompt = template_prompt + " + " + user_input + " + " + color_guidance

4.3 핵심 알고리즘

로고 오버레이 알고리즘

function addLogoToImage(imageUrl, logoBase64) {
    // 생성된 이미지를 Canvas로 로드
    const imageCanvas = await blobToCanvas(imageUrl);

    // 로고 이미지를 Canvas로 로드
    const logoCanvas = await base64ToCanvas(logoBase64);

    // 메인 Canvas 컨텍스트
    const ctx = imageCanvas.getContext('2d');

    // 로고 위치 계산 (왼쪽 상단)
    const padding = 20;
    const logoWidth = 100;
    const logoHeight = (logoCanvas.height / logoCanvas.width) * logoWidth;

    // 로고 합성
    ctx.drawImage(logoCanvas, padding, padding, logoWidth, logoHeight);

    // 결과 이미지 반환
    return imageCanvas.toBlob();
}

7. 발명의 실시예

7.1 실시예 1: 마케팅 이미지 자동 생성

사용 시나리오

기술 회사가 분기마다 제품 마케팅 이미지를 대량으로 제작해야 하는 경우:

  1. UI에서 "기술 이노베이션" 테마 선택
  2. 회사 로고(PNG) 업로드
  3. 프롬프트: "클라우드 컴퓨팅, 블록체인, AI 기술을 표현하는 현대적이고 미래지향적 이미지"
  4. 시스템이 자동으로 100개 이미지 생성 (약 2시간)
  5. 모든 이미지에 일관된 테마와 로고 삽입

결과

기존 방식 대비 시간 120배 단축, 비용 2,500배 절감

7.2 실시예 2: 소셜 미디어 콘텐츠 자동 생성

사용 시나리오

개인 크리에이터가 매일 SNS에 게시할 콘텐츠 제작:

  1. 선호 테마 고정 (예: "미니멀 라이프스타일")
  2. 일일 프롬프트 자동 입력 (API 연동)
  3. 매일 아침 5개의 다양한 포스트 이미지 자동 생성
  4. 개인 로고/워터마크 자동 삽입

결과

월간 150개 이미지 제작으로 콘텐츠 일관성 유지

7.3 실시예 3: 테마 확장

새로운 테마 추가 과정

  1. 테마 관리 메뉴에서 "새 테마 추가" 선택
  2. 테마명: "우아한 미니멀", 설명 입력
  3. 템플릿 이미지(PNG) 업로드
  4. 자동으로 Supabase에 저장
  5. 즉시 드롭다운에 표시되어 사용 가능

8. 청구범위

8.1 독립항

청구항 1

테마 기반 AI 이미지 자동 생성 시스템으로서,
사용자 인터페이스로부터 테마 선택, 로고 업로드, 프롬프트 입력을 받고;
선택된 테마의 메타데이터를 조회하여 프롬프트를 동적으로 구성하고;
OpenAI GPT Image2 API를 호출하여 이미지를 생성하고;
HTML5 Canvas API를 이용하여 로고를 생성된 이미지의 왼쪽 상단에 자동으로 합성하고;
최종 이미지를 Supabase에 저장하고 URL을 반환하는 것을 특징으로 하는 시스템.

청구항 2

제1항의 시스템에 있어서,
입력된 프롬프트의 길이 검증, 파일 형식 검증, 파일 크기 검증을 수행하는 입력 검증 모듈을 추가로 포함하는 것을 특징으로 하는 시스템.

청구항 3

제1항의 시스템에 있어서,
사용자가 새로운 테마를 추가할 수 있도록 하는 테마 관리 인터페이스를 포함하고,
추가된 테마는 자동으로 드롭다운에 반영되는 것을 특징으로 하는 시스템.

8.2 종속항

청구항 4 (청구항 1의 종속항)

제1항에 있어서,
Canvas 기반 로고 오버레이 시 로고의 크기를 동적으로 조절하여
원본 이미지의 10%를 차지하도록 하는 것을 특징으로 하는 시스템.

청구항 5 (청구항 1의 종속항)

제1항에 있어서,
생성된 이미지의 메타데이터(생성 시간, 사용된 테마, 프롬프트)를
데이터베이스에 자동으로 저장하는 것을 특징으로 하는 시스템.

8.3 방법 청구항

청구항 6

테마 기반 AI 이미지 자동 생성 방법으로서,
(a) 사용자로부터 테마, 로고, 프롬프트 입력 수신;
(b) 입력값 검증;
(c) 선택된 테마의 메타데이터 조회;
(d) 사용자 프롬프트와 테마 가이드라인 병합으로 최종 프롬프트 구성;
(e) OpenAI API 호출로 이미지 생성;
(f) Canvas API로 로고 합성;
(g) 최종 이미지 저장 및 URL 반환;
을 포함하는 것을 특징으로 하는 방법.
