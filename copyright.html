프로그램 설명

AI Visual Theme Studio는 미리 정의된 이미지 테마를 기반으로 GPT Image2(DALL-E 3) AI 엔진을 사용하여 고품질의 마케팅 이미지를 자동으로 생성하는 웹 기반 플랫폼입니다.

사용자가 테마를 선택하고 프롬프트를 입력하면, 시스템이 자동으로 이미지를 생성하고 사용자의 로고를 왼쪽 상단에 삽입하는 기능을 제공합니다.

프로그램의 특징

  • 🎯 테마 기반 생성 - 사전에 정의된 이미지 구조와 스타일 기반 생성
  • 🏷️ 자동 로고 삽입 - Canvas API를 이용한 로고 오버레이 기능
  • 🎨 무제한 테마 확장 - 사용자가 새로운 테마를 추가할 수 있는 기능
  • 📊 생성 이력 관리 - Supabase를 통한 데이터베이스 저장
  • 📱 반응형 디자인 - 모바일/태블릿/데스크톱 완벽 지원
  • 🔒 보안 - 환경 변수를 통한 API 키 관리

기술 스택

분류 기술 버전
Frontend HTML5, CSS3, JavaScript (ES6+) Latest
Image AI OpenAI GPT Image2 (DALL-E 3) Latest

Design CSS Grid, Flexbox Modern

2. 기능 명세

2.1 메인 기능 - 이미지 생성

기능 설명

사용자가 선택한 테마와 프롬프트를 기반으로 OpenAI GPT Image2 API를 호출하여 고품질 이미지를 생성합니다.

입력 데이터

  • Theme ID: 선택된 테마의 고유 식별자
  • Prompt: 최대 2,000자의 이미지 생성 프롬프트
  • Logo: 사용자가 업로드한 로고 파일 (JPG, PNG, WebP, GIF)

처리 과정

  1. 입력 데이터 검증 (프롬프트 길이, 파일 형식, 파일 크기)
  2. OpenAI API 호출 및 이미지 생성
  3. Canvas API를 이용한 로고 오버레이
  4. 최종 이미지 Blob 생성 및 URL 생성
  5. 생성 이력 Supabase에 저장

출력 데이터

  • Generated Image URL: 생성된 이미지의 접근 가능한 URL
  • Image Metadata: 생성 시간, 사용된 테마, 프롬프트 등

2.2 보조 기능 - 테마 관리

테마 조회

  • DB에 저장된 모든 테마 목록 조회
  • 테마 이미지 미리보기
  • 테마 상세 정보 표시

테마 추가

  • 테마 이름, 설명, 템플릿 이미지 입력
  • Supabase에 새 테마 데이터 저장
  • 즉시 드롭다운에 반영

2.3 사용자 인터페이스

섹션별 UI

  • 이미지 생성 - 폼 입력, 진행률 표시, 결과 영역
  • 테마 관리 - 테마 추가 폼, 테마 그리드
  • 사용 가이드 - 가이드 카드, FAQ

반응형 디자인

  • 모바일: 단일 열 레이아웃 (최대 767px)
  • 태블릿: 2열 레이아웃 (768px-1023px)
  • 데스크톱: 3열 레이아웃 (1024px 이상)

2.4 세션 및 저장소

로컬 스토리지

  • 세션 데이터 저장 (24시간 TTL)
  • 사용자 설정 저장

데이터베이스

  • 테마 데이터 (image_themes 테이블)
  • 생성 이미지 이력 (generated_images 테이블)

3.3 데이터 흐름

이미지 생성 흐름

  1. 사용자가 폼에 입력 (테마, 프롬프트, 로고)
  2. UI Manager가 입력 검증
  3. API Client가 OpenAI API 호출
  4. Canvas API로 로고 오버레이
  5. 결과 이미지 표시 및 저장

3.4 클래스 구조

APIClient 클래스

OpenAI, Supabase, Vercel API와의 통신을 관리합니다.

  • generateImage() - 이미지 생성
  • addLogoToImage() - 로고 오버레이
  • getThemes() - 테마 조회
  • saveImageHistory() - 이력 저장

UIManager 클래스

사용자 인터페이스 및 상호작용을 관리합니다.

  • handleGenerateImage() - 이미지 생성 처리
  • switchSection() - 섹션 전환
  • loadThemes() - 테마 로드
  • showModal() - 모달 표시

App 클래스

애플리케이션 전체 생명주기를 관리합니다.

  • init() - 초기화
  • checkSession() - 세션 확인
  • checkEnvironment() - 환경 검증

4. 독창적 요소

4.1 기술적 독창성

1️⃣ Canvas 기반 로고 오버레이 시스템

HTML5 Canvas API를 활용하여 생성된 이미지에 동적으로 로고를 삽입하는 기법입니다. 이미지 좌표 계산, 크기 조절, 투명도 처리 등이 포함됩니다.

  • 동적 로고 크기 조절 알고리즘
  • 프로그래매틱 이미지 합성
  • Blob 기반 바이너리 이미지 처리

2️⃣ 테마 기반 이미지 생성 아키텍처

단순히 프롬프트만으로 이미지를 생성하는 것이 아니라, 미리 정의된 테마의 구조를 유지하면서 다양한 콘텐츠를 생성합니다.

  • 테마 메타데이터 스키마
  • 테마별 프롬프트 템플릿 확장
  • 구조 보존 알고리즘

3️⃣ 반응형 웹 디자인 및 인쇄 최적화

모바일부터 데스크톱까지 모든 화면에서 최적의 경험을 제공하며, 동시에 PDF 인쇄도 완벽하게 지원합니다.

  • CSS Grid/Flexbox 기반 동적 레이아웃
  • @media print 최적화
  • 터치 친화적 UI (min-height: 44px)

4.2 디자인 독창성

프리미엄 화이트 테마

모던하면서도 전문적인 느낌의 화이트 톤 기반 디자인입니다.

  • 그라데이션 기반 섹션 배경
  • 컬러 코딩 시스템 (Blue/Purple/Teal/Green)
  • 호버 및 활성화 상태 애니메이션

세그먼트 기반 색상 팔레트

  • Primary (Blue): 메인 액션, 우선순위 높음
  • Secondary (Purple): 보조 액션, 강조
  • Accent (Teal): 정보, 팁
  • Danger (Red): 에러, 경고
  • Success (Green): 성공, 완료

5.2 주요 개발 결정사항

1. 프레임워크 선택: Vanilla JavaScript

React, Vue 등의 프레임워크 대신 순수 JavaScript를 선택한 이유:

  • 빠른 로딩 속도
  • 외부 의존성 최소화
  • 간단한 배포 (정적 파일만 필요)

2. 데이터베이스: Supabase

Firebase 대신 Supabase를 선택한 이유:

  • PostgreSQL 기반 강력한 기능
  • 오픈소스 생태계
  • 유연한 RLS (Row-Level Security)

3. 배포: Vercel

다른 호스팅 서비스 대신 Vercel을 선택한 이유:

  • 정적 웹사이트 최적화
  • 빠른 빌드 및 배포
  • 글로벌 CDN
